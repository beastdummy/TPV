# Fase 3 - Escala Multisede

## Objetivo

Preparar el TPV para crecimiento en volumen, ubicaciones y equipo.

## Modulos de escala

- Puntos de venta multiples por sede.
- Stock por almacen/sede con traspasos.
- Precios y catalogo por sede (si aplica).
- Idiomas y localizacion regional.
- Integraciones externas (contabilidad, ERP, BI).

## Fiabilidad y observabilidad

- Monitorizacion de uptime y errores.
- Alertas operativas (servicio, base de datos, colas).
- Plan de continuidad (runbook de incidentes + rollback).

## Criterios de salida

- Una nueva sede se puede dar de alta sin cambios de codigo.
- La plataforma aguanta picos sin degradacion critica.
- El equipo tiene procedimientos claros para incidentes.
